# Contributing to Flowcast

## Branch Naming Conventions
- `feat/<feature-name>` - New features
- `fix/<bug-name>` - Bug fixes
- `docs/<doc-name>` - Documentation improvements
- `refactor/<name>` - Code refactoring without behavioral change

## Commit Message Conventions
We follow [Conventional Commits](https://www.conventionalcommits.org/):
- `feat: add real-time zone map listener`
- `fix: resolve null route condition in alternative transport`
- `docs: update DB schema diagram`
- `chore: configure tailwind typography`

## Code Style
- Use TypeScript strict mode
- Format code with Prettier
- Ensure component names follow PascalCase, hooks start with `use`, and utility files follow camelCase.
